## CFS03_VR_setting
This repository contains the Unity project used by Group B during the course taught by Professor Jing in the CFS03 Creative Factory Seminar.  

Group B attempted to control a robotic arm in a virtual space using sensors from the real world, and ultimately succeeded not only in control but also in data logging that can be utilized for machine learning.
